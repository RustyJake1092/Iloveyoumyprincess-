# Love You Heart Animation

A small Python animation made with Pygame that displays a glowing heart and floating "love you" text.

## Features

- Animated heart-shaped particle design
- Centered love message with glow effect
- Optional background music if `love_you.mp3` is present in the project folder
- Full-screen-ish canvas sized to 2000x1200

## Requirements

- Python 3
- Pygame

Install dependencies:

```bash
pip install pygame
```

## Run

From the project folder:

```bash
python heart.py
```

## Optional music

Place a file named `love_you.mp3` in the same directory as `heart.py` to have it play automatically.

If the file is missing, the program still runs normally without music.

## Controls

- Press `Esc` to exit
